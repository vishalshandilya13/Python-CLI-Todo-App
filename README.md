# Python CLI To-Do App

A command-line task manager written in Python. Tasks are saved locally in `tasks.json`, so they remain available between runs.

## Features

- Add tasks with optional priority and due date
- View all tasks or only pending tasks
- Update a task's title, priority, or due date
- Mark tasks complete or incomplete
- Delete tasks
- Store tasks locally as JSON

## Run

Requires Python 3. From the project folder, run:

```bash
python todo_cli.py
```

## Project file

- `todo_cli.py` — command-line application and task storage logic.
