# Command-Line To-Do App

A small Python task manager that stores tasks locally in a JSON file.

## Features

- Add tasks with optional priority and due date
- View pending and completed tasks
- Edit task details and mark tasks complete or incomplete
- Delete tasks
- Save task data locally as JSON

## Run

Requires Python 3. The current Python source file is named `Command line and GUI based application` (it does not have a `.py` extension). From this repository folder, run:

```bash
python "Command line and GUI based application"
```

## Note

The repository name mentions a GUI, but the current code is a command-line application.
